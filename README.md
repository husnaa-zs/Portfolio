# Nur Husna Portfolio

Open the folder in VS Code, install the "Live Server" extension, then right-click index.html > Open with Live Server.

Files
- index.html : the content (home, about, projects, ui/ux, contact)
- style.css  : all colours, fonts and layout (colours are at the top, in :root)
- script.js  : project list (P), UI/UX cards (U), parallax and scroll effects

Things to edit first
1. script.js: change the repo names in the P array to your real GitHub repos
2. script.js: replace href:"#" in the U array with your Figma links
3. index.html: replace the placeholder photos in the contact section
4. script.js: paste your Spotify or Apple Music share links in the M array (music button, bottom-right)
